# Research expansion — 2026-11-20

This batch adds **28 publications and technical reports** to the [master bibliography](../metadata/papers.json): RSP-083–RSP-110. The previous indexed count was 82, resulting in **110 indexed records**.

**Verification scope:** Titles, publication years, and downloadable PDF references were checked on original NASA NTRS or DLR electronic-library records. The PDFs were **not downloaded or validated end-to-end in this batch**. These are not new Sider Wisebase imports. Author access/redistribution permissions remain subject to the original source.

## Where to start

- **Internal-ballistics source code and test reconstruction** (RSP-083 through RSP-086): The four NASA SRB-II volumes form a coherent engineering-method, usage, sample-case, and FORTRAN code reference.
- **Nozzle and insulation modeling validation** (RSP-088, RSP-089, RSP-090, RSP-095): Direct measured thermal response, composite damage mechanisms, and ablation-model development.
- **Static-test and plume measurements** (RSP-092, RSP-093, RSP-097, RSP-098, RSP-099, RSP-105): Sensor calibration, heat rates, alumina particulate sizes, and experimental data for benchmarking.
- **Contemporary flight measurements** (RSP-102, RSP-103, RSP-110): DLR flight-test missions and measured hypersonic aerothermal performance.
- **Reacting flow and acoustic coupling** (RSP-104, RSP-109): Reduced chemistry and swirl/nozzle-generated sound relevant to advanced numerical tools.

## Important access caveats

- **RSP-105:** DLR lists an **183 MB** final EMAP report (872 pages). The existing GitHub PDF retrieval script rejects downloads larger than 40 MB. The source link is catalogued, but the download workflow will report a size failure unless its cap and artifact strategy are deliberately revised.
- **NASA archival reports:** The PDF file is listed by NTRS. Some links can fail due to server restrictions or transient errors; repository indexing does not prove that the automated downloader can retrieve it.
- **Bibliographic versus reader verification:** New records are indexed from official source metadata. No file has been claimed to be successfully added to Sider in this round.
- **Related studies:** The EMAP-related studies (RSP-097–099, RSP-105, RSP-108) are distinct articles/reports about the same experimental program. The four SRB-II volumes (RSP-083–086) are intentionally separate volumes.
